# 澳门立体路线地图

一个无需构建步骤的澳门静态地图。它按指定顺序展示 20 个文化路线标记，每站可以打开完整历史说明；收藏店铺以 `S` 独立标记呈现，澳门十六浦索菲特酒店以 `H` 标出，并附 2026 澳门烟花观赏信息。

[在线打开地图](https://kkenny0.github.io/macao-route-atlas/)

![澳门立体路线地图预览](assets/preview.jpg)

## 使用

直接打开仓库根目录的 `index.html`，或运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。不需要 API Key、构建工具或在线地图服务；点击外部资料、店铺实时地图和酒店官网时需要联网。

顶部的“文化路线 / 收藏店铺 / 烟花观赏”同时切换地图与资料面板。桌面并排显示，手机上下排列，分类入口在滚动时保持可见。烟花日期与场次固定在面板顶部，观赏点列表单独滚动；无需翻到页面底部查找。分类按钮支持方向键、Home 和 End 切换。

地图支持拖动平移、滚轮或双指缩放、旋转、切换 2D/3D 视角；缩放范围为初始视图的 0.3～8 倍，按钮与键盘 +/- 使用相同范围。北向指示随旋转和俯仰更新。文化路线可以查看全程或三个分段，站点列表随分段更新；店铺与烟花在各自分类显示独立标记，同时保留绿色文化路线与 20 个站点作为位置参照，酒店以 H 标出。概览取景同时包含文化路线与当前分类地点；点击当前分类的店铺或观赏点会保留手动选择的缩放，地点在屏幕外时自动平移至可见区域。重置视角或切换分类可返回概览。路线参照点按真实位置绘制，缩放到足够空间时显示站号，起点妈阁庙与终点美高梅另有文字标识。地图标记通过引线连接实际位置，密集区域的编号会适度避让。收藏店铺按屏幕上的距离聚合为“几家”数量标记，点击或按 Enter 可放大展开；达到最大缩放时不再合并店铺标记。同一聚合内的店铺也始终可以从列表或选择菜单直接定位。点击“全屏”让地图与联动资料铺满当前页面，分类入口保持可用；点击退出按钮即可恢复。

地图按空间显示澳门半岛、氹仔、路氹，以及湖泊、主要桥梁和地标名称；缩小时优先保留区域名称，详细名称按比例与可用空间显示。标注位置参照[澳门旅游局地图](https://content.macaotourism.gov.mo/uploads/mgto_main/2020_Oct1_FoodGuide_sc.pdf)，是区域与地标的大概位置，不表示行政边界、建筑入口或导航坐标。离线几何数据覆盖范围有限，缩至最小后周边可能留白。

点击地图编号或站点名称可以阅读历史档案，档案内可按顺序切换上一站和下一站。店铺列表的“地图定位”和地图内的“选择地点”菜单支持跳转到店铺、酒店或观赏区域；全屏中也可切换分类、查看详情。地图上的地点标记支持键盘焦点与点击。

`S` 编号仅供查找，不加入文化路线。店址及坐标已参考 Google 地图核对；银河 Blooom 仅以商场区域示意，历史资料列 K110，同名 Google 地图条目暂未找到。尚未确认具体分店的收藏保留卡片，不猜测坐标。

## 2026 烟花观赏

- 燃放海域：澳门旅游塔对出海面，`F` 标记为海域示意，非烟花船的精确位置。
- 10 月 1 日与 10 月 4 日：均为澳门当地时间 **21:00、21:40**；10 月 4 日 **22:00** 另有无人机闭幕表演。
- `V1—V5`：澳门旅游塔周边、南湾湖水上活动中心、南湾 · 雅文湖畔、沙格斯大马路、科学馆至观音像海滨。V5 的紫色线段表示区域范围。

节目时间依据[澳门旅游局 2026 年 10 月活动资料](https://www.macaotourism.gov.mo/zh-hans/events/whatson/13795/?month=10)，核对日期为 2026-09-30。观赏区域按收藏清单整理；V3、V4 及 V5 所涵盖的沿岸地点也列于官方观赏地点清单。活动安排与现场开放情况以主办方公告为准。

## 路线与内容

1. 妈阁庙 → 主教山小堂 → 亚婆井前地 → 郑家大屋 → 圣老楞佐教堂 → 圣若瑟修院 → 何东图书馆
2. 圣奥斯定教堂 → 岗顶剧院 → 市政署大楼 → 仁慈堂 → 玫瑰圣母堂 → 大三巴牌坊 → 大炮台
3. 疯堂斜巷 → 东望洋新街 → 加思栏花园 → 老葡京 → 永利澳门 → 美高梅

线段表达站点先后关系，**不是实际步行导航**。街道、出入口、开放时间以及店铺是否营业，请以当时的实时地图和现场信息为准。建筑高度仅用于立体效果。

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构、入口和地图署名 |
| `src/styles.css` | 页面样式与响应式布局 |
| `src/app.js` | 地图绘制、视角控制、站点及历史档案交互 |
| `data/content.js` | 20 站史料、店址与坐标、酒店标记、2026 烟花资料 |
| `data/map.js` | 离线地图几何数据、地名标注及参考来源 |

店铺名称、店址、经纬度及资料链接可在 `data/content.js` 的 `shops` 中维护；烟花地点与时间在 `fireworks` 中。路线地点在同文件的 `route` 中按数组顺序排列；调整顺序时也要同步检查编号、阶段和历史档案翻页逻辑。
